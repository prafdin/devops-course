% Общие инструкции для всех лабораторных работ
\newcommand{\commoninstructions}{
    \section*{Общие инструкции}

    \subsection*{Рекомендации к выполнению}
    \begin{itemize}
        \item Настоятельно рекомендуется выполнять команды из листинга отдельно, одну за другой.
        \item Рекомендуется копировать команды через промежуточную вставку в текстовый редактор во избежание лишних символов.
        \item Перед началом работы ознакомтесь с
            \href{https://prafdin.github.io/devops-course/2026/assignments/00-howto.pdf}{инструкцией по сдаче лабораторных работ}.
    \end{itemize}

    \subsection*{Требования к выполняемой работе}
    \begin{itemize}
        \item Добавьте в репозиторий все необходимые файлы: код приложения, файлы конфигурации и скрипты и т.д.
    \end{itemize}
    
    \newpage
}
