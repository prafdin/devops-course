    \begin{frame}{IT инфраструктура}
        IT инфраструктура - совокупность аппаратных и программных средств для разработки, развертывания и эксплуатации
        информационных систем организации.
        \vspace{0.3cm}

        Компоненты инфраструктуры:
        \begin{enumerate}
            \item IT оборудование: серверы, маршрутизаторы, железные фаерволы и т.д.
            \item Сетевые ресурсы: локальные сети, интернет соединения, DNS серверы и т.д.
            \item Программное обеспечение: операционные системы, гипервизоры, БД, системы ведения проектов и т.д.
        \end{enumerate}
    \end{frame}

    \begin{frame}{On premise}
        On premise - модель размещения IT инфраструктуры на собственных серверах компании.

        Компания обеспечивает:
        \begin{enumerate}
            \item Физическую инфраструктуру: дата центр, каналы связи и т.д.
            \item Закупку, настройку и обслуживание серверов и сетевой инфраструктуры
            \item Установка, настройка и обслуживание ПО
        \end{enumerate}
    \end{frame}

    \begin{frame}{Colocation}
        Colocation - модель размещения аппаратных средств IT инфраструктуры во внешнем дата центре, сохраняя полный
        доступ к размещенным ресурсам.

        Компания обеспечивает:
        \begin{enumerate}
            \item Закупку серверов
            \item Установка, настройка и обслуживание ПО
        \end{enumerate}
    \end{frame}

    \begin{frame}{Hosting (VPS, VDS)}
        Hosting - модель IT инфраструктуры, при которой компания арендует вычислительные мощности у сторонней компании.

        Компания обеспечивает:
        \begin{enumerate}
            \item Установка, настройка и обслуживание ПО
        \end{enumerate}
    \end{frame}

    \begin{frame}{Public cloud}
        Public cloud - модель IT инфраструктуры, при которой вычислительные ресурсы принадлежат стороннему провайдеру и
        предоставляются множеству клиентов по запросу через интернет.

        Преимущества перед Hosting:
        \begin{enumerate}
            \item Гибкость и масштабируемость, экономичность
            \item Надёжность и отказоустойчивость
            \item Управление ресурсами через API
            \item Широкий набор облачных ресурсов - разные модели облачных услуг
        \end{enumerate}

        Популярные облака: AWS, Azure, Google Cloud, Yandex Cloud, Cloud.ru и т.д.
    \end{frame}

    \begin{frame}{Private cloud}
        Private cloud - разновидность on premise IT инфраструктуры, при которой вычислительные ресурсы предоставляются по запросу
        внутренним потребителям внутри компании.

        Преимущества перед on premise:
        \begin{enumerate}
            \item Удобство для конечных потребителей
            \item Управление ресурсами через API
            \item Разные модели облачных услуг$^{*}$
        \end{enumerate}

        Решения для создания private cloud: VMware vSphere, OpenStack, Proxmox и т.д.
    \end{frame}
