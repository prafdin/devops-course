    \begin{frame}{Infrastructure as Code}
        Инфраструктура как код (Infrastructure as Code, IaC) - модель управления IT инфраструктурой, при которой
            инфраструктурные ресурсы описываются в виде кода.

        Преимущества такого подхода:
        \begin{itemize}
            \item Появляется инструментарий для работы с кодом: git, CI/CD, MR, Code Review, тесты
            \item Самодокументирование
            \item Воспроизводимость
            \item Гибкость управления
        \end{itemize}
    \end{frame}

    \begin{frame}{Terraform}
        \href{https://developer.hashicorp.com/terraform}{Terraform} - типичный инструмент управления инфраструктурой по модели IaC.
        Для описания инфраструктуры используется язык конфигурации \href{https://developer.hashicorp.com/terraform/language/syntax/configuration}{HCL}.

        Поддерживает:
        \begin{itemize}
            \item Публичные облака (AWS, Azure, Yandex Cloud и др.)
            \item Приватные облака
            \item Гипервизоры
            \item K8S
            \item \href{https://registry.terraform.io/browse/providers}{Другое}
        \end{itemize}
    \end{frame}
