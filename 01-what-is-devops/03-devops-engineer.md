# Подводка (30 секунд):

"У вас может возникнуть вопрос: если DevOps - это культура для всех, то зачем существует должность 'DevOps инженер'?
Давайте разберемся."

# Объяснение роли (2 минуты):

"DevOps - это действительно культура и практики для всей команды. Но на практике кто-то должен настраивать CI/CD
пайплайны, управлять инфраструктурой, внедрять автоматизацию, быть связующим звеном между разработчиками и админами. Вот
для этого и появился DevOps инженер."

# Аналогия (1.5 минуты):

"Простая аналогия: Agile - это методология для всей команды. Но есть Scrum Master, который помогает команде правильно
применять Agile. Так же и здесь: DevOps - культура для всех, DevOps инженер - помогает эту культуру внедрять." 
(Fallback на строительство дома и прораба)

# Главная мысль (1 минута):

"Запомните: DevOps инженер не делает DevOps за всех. Он учит команду делать это правильно. Он - катализатор изменений, а
не единственный ответственный за DevOps."
