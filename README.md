# Курс DevOps

## План курса

1. **Введение в DevOps** - что такое DevOps, культура и принципы
2. **Прокси и туннелирование** - Nginx, FRP и доступ к удаленным сервисам
3. **Системы контроля версий в DevOps** - Git в контексте DevOps
4. **CI/CD: концепции и инструменты** - непрерывная интеграция и доставка
5. **Configuration Management** - управление конфигурацией с Ansible
6. **Контейнеризация** - Docker и контейнерные технологии
7. **Оркестрация** - Docker Compose и многоконтейнерные приложения
8. **Cloud + Baked Configuration** - Packer и создание готовых образов в Яндекс Облаке
9. **Infrastructure as Code** - Terraform для автоматизации инфраструктуры
10. **DevSecOps** - интеграция безопасности в DevOps процессы
