# Курс DevOps

## План курса

1. **Введение в DevOps** - что такое DevOps, культура и принципы
2. **Системы контроля версий в DevOps** - Git в контексте DevOps
3. **CI/CD: концепции и инструменты** - непрерывная интеграция и доставка
4. **Инфраструктура как код (IaC)** - управление конфигурацией
5. **Контейнеризация и оркестрация** - Docker и контейнерные технологии
6. **Мониторинг и логирование** - наблюдаемость систем
7. **DevSecOps** - безопасность в DevOps
8. **Deployment стратегии** - стратегии развертывания
