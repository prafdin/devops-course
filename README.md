# Курс DevOps

## План курса

1. **Введение в DevOps** - что такое DevOps, культура и принципы
2. **Системы контроля версий в DevOps** - Git в контексте DevOps
3. **CI/CD: концепции и инструменты** - непрерывная интеграция и доставка
4. **Configuration Management** - управление конфигурацией с Ansible
5. **Контейнеризация** - Docker и контейнерные технологии
6. **Оркестрация** - Docker Compose и многоконтейнерные приложения
7. **Cloud + Baked Configuration** - Packer и создание готовых образов в Яндекс Облаке
8. **Infrastructure as Code** - Terraform для автоматизации инфраструктуры
9. **DevSecOps** - интеграция безопасности в DevOps процессы
